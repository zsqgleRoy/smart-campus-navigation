# 🎉 Smart Campus Navigation v3.5.14 - First Release

## 📱 Application Overview

**Smart Campus Navigation** (数智成贤) is a website navigation app designed for campus students and faculty, helping you quickly access commonly used campus websites and services. This version is the first official release of the native Android application.

## ✨ Core Features

### 🔍 Smart Search
- Search websites by name or description
- Real-time search results
- Search history tracking

### ⭐ Favorites Management
- One-tap bookmarking of favorite websites
- Quick access to favorites list
- Organized favorites by category

### 📊 Visit History
- Automatically records recently visited websites
- Quick browsing of history
- Support for clearing history

### 🎨 Category Browse
- Browse websites by category
- Horizontal sliding tabs
- Intuitive website card display

### 🌓 Theme Switching
- **Light Mode** - Bright and clear daytime theme
- **Dark Mode** - Eye-friendly nighttime theme
- **Eye-care Mode** - Warm color scheme to reduce eye strain
- One-tap quick switching

### 📱 Built-in Browser
- Integrated WebView for website browsing
- Automatic theme adaptation for web pages
- Smooth browsing experience

### 💾 Offline Support
- Room Database for local data storage
- Icon preloading and caching
- Offline browsing of visited websites

## 🛠️ Technical Highlights

- **Modern UI** - Built with Jetpack Compose, featuring smooth Material Design 3 interface
- **MVVM Architecture** - Clean code structure, easy to maintain and extend
- **Performance Optimized** - Icon preloading, data caching, smooth page transitions
- **Low Memory Usage** - Optimized resource management, suitable for various devices
- **Minimal Permissions** - Only requests necessary network permissions, protects user privacy

## 📋 System Requirements

- **Android Version**: 5.0 (API 21) and above
- **Target SDK**: Android 14 (API 34)
- **Storage Space**: Approximately 15 MB
- **Network**: Internet connection required to access websites

## 🎯 User Guide

### First Time Use
1. The app will automatically initialize the database when opened
2. Wait for icon preloading to complete (runs in background, doesn't affect usage)
3. Start browsing and searching websites

### Main Operations
- **Search Websites**: Enter keywords in the home page search bar
- **Bookmark Websites**: Tap the favorite icon on website cards
- **View History**: Switch to "Recent Visits" tab in the "Favorites" page
- **Switch Theme**: Tap theme icons in the "Settings" page
- **Browse Websites**: Tap website cards to open websites in-app

## 🐛 Known Issues

- Some low-performance devices may require a brief wait when switching pages quickly
- Icon loading may take a few seconds on first launch
